Client-Server Communication with XOR Encryption

This project demonstrates a secure client-server communication system using TCP sockets in Python, with messages encrypted using a XOR cipher. It includes a Flask-based web frontend for sending messages and receiving server acknowledgments in real time.

Features:
Encrypts and decrypts messages using XOR cipher
Supports multiple clients with multithreaded server
Displays original message and server acknowledgment on a web interface
Includes timestamps for messages and acknowledgments
Perfect for learning socket programming, simple encryption, and Python web integration
